Algorithm

Push(S, x)  if top = MAX - 1 then      error "overflow"  top ← top + 1  S[top] ← x
Pop(S)  if top = -1 then      error "underflow"  x ← S[top]  top ← top - 1  return x
Peek(S)  if top = -1 then      error "empty"  return S[top]

The highlighted lines are the ones that just ran. None of the three operations has a loop, so each takes O(1) time however many elements are stored. The array itself takes O(n) space for n elements.
